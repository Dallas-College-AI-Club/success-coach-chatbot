### Method notes (what this example teaches)
- Nine Criteria rows reconcile EXACTLY to the printed "Total Points / 1100" checksum
  (30+500+100+100+30+150+100+50+40) — the checksum row itself is excluded. Reconciling
  is evidence FOR the parse; the remaining ambiguities still cap confidence at medium.
- Dropped-lowest scoring ("6 taken, one dropped") lives in each row's notes; the row's
  points stay the printed TOTAL for the row, never recomputed for drops.
